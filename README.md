# terraform-provider-ergo

Terraform and OpenTofu provider to manage ergo decisions, scopes and waivers as code.

> Status: skeleton. The provider lands in a later change.

The Terraform Registry naming rule is why this provider has its own repository. It will manage decisions, scopes and waivers through the ergo API. The license is MPL-2.0, the ecosystem norm for Terraform providers.
